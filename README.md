# Carte de visite virtuelle

Carte de visite interactive et personnalisable (fond, nom, société, contact, QR code, ajout aux contacts).

## Lancer en local
Ouvrir simplement `index.html` dans un navigateur, ou :

```bash
docker build -t carte .
docker run -p 8080:80 carte
```

Puis ouvrir http://localhost:8080
